# Sightengine review: what it is good at and where it runs out

**Bottom line:** Sightengine is a strong choice when images and video are your problem. It documents 136 classes across 26 models, has a permanent free tier, and counts a nudity check on an image as one operation. It is less specialised for text: six ML classes, seven ML languages, and no conversation context option in the docs we read. Add a text-first layer such as Supervisor if scams, spam and contextual abuse are what hurt your community.

We make Supervisor, a competing moderation API, so treat this as an interested party's assessment. Every Sightengine claim comes from Sightengine's own pricing and documentation pages, linked at the end and read on 26 October 2026. Where we could not read something, we say so.

## What Sightengine is

Sightengine's pricing page lists four products: image moderation ("150+ moderation classes for your images"), video moderation including live streams, text moderation, and audio moderation. Output is a score per class. In its text docs: "Scores are between 0 and 1, and they reflect how likely it is that someone would find the text problematic."

Requests authenticate with an `api_user` and an `api_secret`. The docs show curl, Python, PHP and Node examples using plain HTTP calls. We did not find an official SDK package or install command in the pages we read, so you should expect to write a thin client yourself.

## What Sightengine does well

**Visual breadth is the standout.** The classes page says "Sightengine provides 136 classes across 26 models." The standard models cover nudity and adult content (31 classes alone), violence, weapons, gore, hate and offensive imagery, and self-harm. Restricted categories include recreational drugs, alcohol, tobacco, medical, gambling and money. There is also a model for reading profanity and personal information out of text inside images.

**It goes well beyond moderation.** The changelog shows steady additions: AI-generated image and video detection (with new generator classes added as recently as October 2026), face liveness in March 2026, recapture detection in April 2026, and AI speech and music detection. Pro adds age estimation. If you need to know whether media was generated by a model, this is not something a text-first API gives you.

**The free tier is real.** 2,000 operations a month, up to 500 a day, with no time limit, according to the FAQ.

**Billing is forgiving.** Failed requests are not counted, and overage is simply charged at the per operation rate.

**Video and live streams scale with the plan.** Starter takes videos up to 50 MB without live streams. Pro takes up to 500 MB with live moderation, at 10 requests a second against Starter's 1.

**Rule-based text coverage is wide.** The pattern-matching classes include profanity, personal information, links, extremism, weapons, medical, drugs, self-harm, violence, spam, content trade and money transactions, plus a custom blacklist.

**Active development.** The changelog has entries in nearly every month of 2026.

## Where Sightengine runs out

**Text is a smaller part of the product.** The ML text classes are sexual, discriminatory, insulting, violent, toxic and self-harm. We did not find classes named scam or promotional in the text docs, though the rule-based spam class covers "attempts to send or lure the user to another platform".

**Languages are narrower than a community may need.** ML text: English, French, Italian, Portuguese, Spanish, Russian and Turkish. Rule-based: eighteen languages. Other languages are "available upon request". The docs say nothing we could find about slang or mixed-language messages.

**Text is scored per item.** The docs describe submitting a text item and receiving scores for it. We did not find a documented way to say "this message needs the surrounding conversation" in the pages we read.

**The text pricing rule is not published.** Plans are in operations, and how many a text request uses is not readable on the public pricing page.

**Currency is unclear.** The page shows only a "$".

**Plan limits matter.** Starter allows 1 request per second and one concurrent video job. Free is capped at 500 operations a day.

## Who Sightengine is right for

- **Image and video platforms** that need breadth of visual classes.
- **Products that need AI-generated media detection, liveness or age checks** alongside moderation.
- **Teams who want a free tier to prototype on** with no expiry.

It is a weaker fit for communities where the damage is done in text, such as scams, harassment that only makes sense in context, and multilingual chat.
